# Audio and Beatitudes music status

The supplied development materials include five Sigrid a cappella recordings,
a Beatitudes lyric document, a Python generator, and a GarageBand project. They
are useful creative references, but they are **not included in the Lamplight
runtime or repository distribution**.

Known source filenames outside this repository:

- `Sigrid_Acapella_1.m4a`
- `Sigrid_Acapella_2.m4a`
- `Sigrid_Acapella_3.m4a`
- `Sigrid_Acapella_4.m4a`
- `Sigrid_Acapella_5.m4a`
- `Beatitudes_Lyrics.rtf`
- `Beatitudes_Generator.py`
- `Beatitudes.band.zip`

## Release gates for any future audio module

1. Identify the composer, lyricist, arranger, performer, producer, and owner of
   each master recording.
2. Obtain written permission covering app-store, web, Linux, download, offline
   caching, editing, and worldwide distribution. Record whether the permission
   is revocable, time-limited, or attribution-dependent.
3. Distinguish verbatim Scripture from mnemonic paraphrase. Cite the translation
   for verbatim quotation and label original/paraphrased lyrics accurately.
4. Produce a final mix/master rather than shipping an unfinished DAW project.
5. Normalize intelligibility and loudness consistently, check peaks, remove
   unintended noise, and test phone speakers, headphones, and accessibility
   interactions.
6. Provide captions/lyrics and a non-audio path to the same learning content.
7. Give learners independent controls for music, voice, sound effects, autoplay,
   and download/storage. Respect reduced motion and interruption behavior.
8. Update privacy, licenses, app size, offline cache, QA, and store disclosures.

Until those gates are complete, source recordings must stay outside `www/`,
native bundles, Electron packages, GitHub releases, and public repositories.
