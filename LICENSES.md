# Lamplight Licenses, Notices, and Credits

This file inventories material intentionally included in the Lamplight source
repository. The lockfile remains the authoritative list of installed package
versions. Release maintainers must regenerate a full dependency-license report
from the lockfile and inspect the packaged artifacts before distribution.

## Lamplight project material

To the extent protectable rights subsist and are owned by him, application-
specific code, interface copy, artwork, documentation, and project
configuration are copyright © 2026 Kenneth W. Sparks. All such rights are
reserved unless a file expressly says otherwise. See [`LICENSE`](LICENSE).

The repository is marked `UNLICENSED` deliberately. Making an app free of
charge does not make its source code open source. Kenneth should choose an
explicit open-source or source-available license before inviting code
contributions or granting reuse rights.

Development included assistance from generative-AI systems. That disclosure
does not determine copyright ownership or grant any additional permission.

## Scripture: World English Bible

The embedded Scripture is identified by the existing project as the **World
English Bible (WEB)**. The WEB text is dedicated to the public domain. “World
English Bible” is a trademark of eBible.org and is used as a courtesy credit,
not as an endorsement.

- Project: <https://worldenglish.bible/>
- Public-domain statement: <https://worldenglish.bible/faq.htm>
- Included notice: [`third_party_licenses/WEB-PUBLIC-DOMAIN-NOTICE.md`](third_party_licenses/WEB-PUBLIC-DOMAIN-NOTICE.md)

**Release gate:** the original source URL, WEB edition/revision, download date,
and source-file checksum used to construct the embedded corpus were not present
in the inherited project. Record them in `docs/CONTENT_PROVENANCE.md` before a
store release. Do not silently substitute another Bible translation.

## Embedded fonts

The application identifies its embedded WOFF2 subsets as:

- **Fraunces**, credited to Undercase Type and the Fraunces project
  contributors.
- **Barlow**, credited to Jeremy Tribby and the Barlow project contributors.

Both font families are distributed under the SIL Open Font License 1.1. The
complete license is included at
[`third_party_licenses/OFL-1.1.txt`](third_party_licenses/OFL-1.1.txt).

**Release gate:** retain the upstream font files' exact copyright strings,
version identifiers, and Reserved Font Names when recreating or replacing a
subset. Those details were not preserved alongside the inherited embedded
font data.

## Application frameworks and build tools

Lamplight's source scaffold directly references the following third-party
packages. Versions are pinned in `package.json` and `package-lock.json`.

| Component | Use | License |
|---|---|---|
| Capacitor Core, iOS, Android, CLI | Native application runtime and tooling | MIT |
| Capacitor App | Native lifecycle and back-button integration | MIT |
| Capacitor Preferences | Local key/value persistence | MIT |
| Electron | Linux desktop runtime | MIT |
| electron-builder | Linux packaging tooling | MIT |
| Gradle Wrapper | Reproducible Android build bootstrap | Apache-2.0 |

The standard MIT license text is included at
[`third_party_licenses/MIT.txt`](third_party_licenses/MIT.txt). Each project
retains its own copyright notice; consult its package metadata and installed
license file. Transitive packages remain governed by their own licenses.
The Gradle Wrapper license is included at
[`third_party_licenses/Apache-2.0.txt`](third_party_licenses/Apache-2.0.txt).
Electron packages generated by electron-builder also include Electron and
Chromium notices; confirm those generated notices are present in every release
artifact.

The optional `@capacitor/assets` generator is intentionally not installed.
Version 3.0.5 brought obsolete vulnerable image/archive dependencies into the
build graph during the August 2026 audit. Native icons and launch assets must be
created from the checked-in masters with reviewed Xcode and Android Studio tools
until a safe replacement is approved.

No Sigrid recording, Beatitudes lyric sheet, GarageBand project, or generated
music file is included in the runtime. Their status is documented in
[`docs/AUDIO_AND_MUSIC.md`](docs/AUDIO_AND_MUSIC.md).
